# 小程序上传说明（不用微信开发者工具）

## 步骤

### 1. 下载上传密钥
- 登录 https://mp.weixin.qq.com
- 开发 → 开发管理 → 开发设置
- 找到"小程序代码上传" → 点击"生成"
- 下载密钥文件（文件名类似 `private.xxxxxxx.key`）

### 2. 放置密钥文件
- 把下载的密钥文件**改名**为 `private.key`
- 放到本文件夹（Applet）根目录下

### 3. 安装 miniprogram-ci
打开命令行，运行：
```bash
npm install -g miniprogram-ci
```

### 4. 上传代码
```bash
node upload.js
```

### 5. 手机查看体验版
- 上传成功后，登录微信公众平台
- 版本管理 → 体验版 → 扫码体验
- 手机微信扫码即可打开

---

## 注意事项
- 密钥文件不要泄露给别人
- 每次改代码后，重新运行 `node upload.js` 即可
- 不需要安装微信开发者工具
